- 合计127008个场景全部收敛，无失败场景；总计算时间372 s，单个场景约2.9 ms（4个并行计算）。
- 无功限值转换轮数：厚尾检验场景中55.2%为2轮（1次转换），43.9%为3轮，852个场景4轮，1个场景5轮，8个场景无机组越限。与OP1相比，3轮场景比例由11.8%升至43.9%，平均迭代由6.37次升至7.98次，原因是OP2基础运行点有14台机组距无功限值不足1 Mvar（OP1为10台），误差引起的无功限值转换更频繁。
- 源荷输入：风电4站与光伏6站出力=日前预测+误差（限于[0, 装机]）；各节点负荷乘以1+0.01ξ。
- 潮流：直角坐标牛顿-拉夫逊法，未知量含系统不平衡量，19台机组按Pmax比例分担；方程残差<10⁻¹⁰ p.u.；机组无功限值规则同阶段B。

## 文件

文件格式与字段同`../OP1/README.md`：每组按5000个场景分块，`<场景组>_chunkNNN.npz`；`strength_w`含风电、光伏两组波动强度变量（高斯copula为1）。`stage_d_summary_OP2.json`记录各组计算时间、迭代次数、转换轮数分布与失败场景（无）。
