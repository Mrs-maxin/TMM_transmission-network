## 文件

每组按5000个场景分块：`<场景组>_chunkNNN.npz`，字段：

- `V`：节点复电压（p.u.，按文件节点顺序1–118）；`Pg_MW`、`Qg_Mvar`：54台机组出力（按文件机组顺序）；`mode`：53台非平衡机组运行方式（0调压，1无功上限，−1无功下限）；
- `Pf_MW`、`Qf_Mvar`、`Pt_MW`、`Qt_Mvar`：186条支路首端、末端功率（按文件支路顺序）；
- `imbalance_MW`：系统不平衡量；`converged`、`fail_code`、`iterations`、`rounds`、`max_P_residual_pu`；
- 输入：`Pren_MW`（10个场站有功，按`renewable_mapping.csv`顺序）、`load_factor`（118个节点负荷倍率）、`strength_w`（各技术组波动强度变量，高斯copula为1）、`scenario_index`。
- 读取：`tmm_cloud.montecarlo.load_set(sorted(glob("check_heavy_chunk*.npz")))`。

`stage_d_summary_OP1.json`记录各组计算时间、迭代次数、转换轮数分布与失败场景（无）。
