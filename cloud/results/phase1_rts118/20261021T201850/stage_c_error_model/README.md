# 阶段C：含共同波动强度的新能源预测误差模型

计算入口：`python cloud/tests/run_stage_c_error_model.py`；计算程序`cloud/tmm_cloud/error_model.py`；输入为阶段B结果`../../20261021T201240/stage_b_network/`的运行点与场站映射，以及`data/rts_gmlc/`。

## 计算内容

1. **相近历史小时**：以10个映射场站日前预测占装机比例构成的向量计算欧氏距离，取与运行点最近的k=750个历史小时（2020年）。OP1光伏预测为零，距离自动选出夜间及傍晚小时（0–6时、16–23时）；OP2选出7–15时的白天小时。距离中位数/最大值：OP1为0.38/0.50，OP2为0.49/0.56。这些小时的误差（实时小时平均减日前预测，按阶段B装机系数0.2611缩放）用于建模。
2. **逐站边缘分布**：对相近小时误差作高斯核平滑（Silverman带宽），由累积分布函数的数值反函数抽样；超出运行点物理范围（预测+误差∈[0, 装机]）的值取为边界值，即出力为零或满发。OP1风电满发概率3.9%–9.6%，零出力概率1.7%–5.8%；OP2风电零出力概率3.3%–17.5%（309_WIND_1、303_WIND_1预测仅占装机8%、2%）。
3. **相关结构**：
   - t copula：相关系数矩阵由Kendall τ按sin(πτ/2)换算，自由度ν由最大似然估计，其共同的卡方变量即共同波动强度；
   - 分组t copula（OP2风电与光伏同时存在时）：风电、光伏各有一个相互独立的波动强度，高斯部分保留全部相关系数，似然由Gauss-Laguerre求积计算（单组时求积值与解析值739.1534一致）；
   - 高斯copula：与上述模型边缘分布相同，没有共同波动强度，作为轻尾比较模型。
   - 厚尾模型按AIC在单一强度与分组强度之间选择。
4. **负荷**：各节点负荷乘以1+0.01ξ（ξ为相互独立的标准正态变量），有功、无功同一倍率，功率因数不变，作为次要随机源（RTS-GMLC区域负荷不含随机预测误差，见阶段A）。

## 判断

- 运行点条件下，RTS-GMLC新能源误差的共同波动强度可由t类copula表示：OP1的t copula对高斯copula的似然比统计量为25.5，OP2分组t copula的AIC比高斯copula低221（已由数值实验支持）。
- OP2分组t copula复现了总误差的厚尾（超额峰度2.56，历史2.14；99.5%分位数279 MW，历史277 MW），高斯copula在边缘分布相同时总误差超额峰度只有1.60（已由数值实验支持）。
- 误差平方相关系数被模型低估：OP2光伏组间历史0.34，分组t copula 0.20；OP1风电历史0.26，t copula 0.23。原因尚未查明，可能与750个相近小时内预测水平不同引起的离散度变化有关，后续可缩小相近小时范围或按预测水平标准化后再检验（尚未验证）。
- OP1的厚尾主要体现在相关结构上：逐站条件误差接近轻尾（超额峰度≤0.55），两种模型总误差分位数差别不超过8 MW。由此预期OP1中厚尾对电压与线路功率的影响较小（仅为当前假设，阶段E检验）。
- 与任务说明的差别：OP2的厚尾模型由单一强度t copula改为按风电、光伏分组的t copula，理由是AIC差150且单一强度不能同时表示两组的强度；单一强度t copula的参数仍保存在模型文件中（`nu`、`R_t`）。
