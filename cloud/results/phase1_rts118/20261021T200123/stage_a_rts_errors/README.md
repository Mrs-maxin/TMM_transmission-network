# 阶段A：RTS-GMLC 2020年新能源与负荷预测误差统计

计算入口：`python cloud/tests/run_stage_a_rts_errors.py`；数据：`data/rts_gmlc/`（来源提交与SHA256见`data/rts_gmlc/SOURCE.md`）。

## 计算内容

预测误差定义为实时5分钟出力按小时平均后减去日前逐时预测（2020年8784小时）。风电4个场站（装机合计2507.9 MW）取全部小时；25座集中式光伏只取白天小时（日前预测或实时小时平均出力大于零，单站约4361–4532小时）。逐站计算误差标准差、超额峰度、1%/99%分位数，计算站间误差相关系数和标准化误差平方的相关系数（共同波动强度指标），并按日前预测占装机比例分10档统计误差标准差。

## 主要数值

| 对象 | 误差标准差（占装机） | 超额峰度 | 站间误差相关系数均值 | 站间误差平方相关系数均值 |
| --- | --- | --- | --- | --- |
| 风电4站 | 22.5%–25.8% | 2.81–4.08 | 0.40 | 0.31（按预测档标准化后0.28） |
| 光伏25站（白天） | 9.4%–17.0%（中位数15.9%） | 3.56–9.36（中位数3.94） | 0.34 | 0.26（按预测档标准化后0.24） |
| 风电合计 | 462 MW（18.4%） | 2.94 | | |
| 光伏合计（白天） | 139 MW（9.0%） | 1.62 | | |

- 风电合计误差与光伏合计误差在白天的相关系数为0.07。
- 风电误差1%/99%分位数约为装机的±(66%–75%)，如317_WIND_1为−575/+588 MW。
- 误差离散度随预测水平变化：风电误差标准差在预测0–10%装机档约16%–19%装机，在50%–80%档升至29%–33%，在90%以上档降至14%–23%（受出力上限约束）；光伏中位数在10%–20%档约21%，60%–80%档约11%–12%。按预测档标准化后，风电单站超额峰度升至4.6–8.7，说明厚尾不只来自预测水平不同造成的离散度差异。
- 区域负荷：实时值与日前值之比在全年为常数（区域1、2、3约0.920、0.998、0.994，逐时标准差约2×10⁻⁵）。该数据只含固定比例偏差，不含随机负荷预测误差，区域1的−111 MW平均偏差为固定比例造成。

## 判断

- RTS-GMLC风电预测误差存在明显厚尾（单站超额峰度2.8–4.1）和共同波动强度（站间误差平方相关系数0.18–0.54，均值0.31），与之前的快速核查一致（已由数值实验支持，本目录CSV）。
- 光伏白天误差同样厚尾（中位数超额峰度3.9），站间误差平方相关系数均值0.26（已由数值实验支持）。
- RTS-GMLC区域负荷不能提供负荷随机波动，后续负荷随机波动按任务说明取变异系数1%的独立高斯波动，作为次要随机源（已由数值实验支持，数据为常数比例）。
- 误差离散度依赖预测水平，后续误差模型按与运行点预测相近的历史小时建立条件模型（阶段C）。

## 文件

- `wind_error_site_statistics.csv`、`pv_error_site_statistics.csv`：逐站统计。
- `wind_error_corr.csv`、`pv_error_corr.csv`：误差相关系数；`*_sq_std_error_corr.csv`：标准化误差平方相关系数；`*_sq_condstd_error_corr.csv`：按预测档标准化后的误差平方相关系数。
- `error_spread_by_forecast_level.csv`及`*_spread_vs_level.png`：误差离散度与预测水平。
- `wind_total_error_hist_log.png`：风电合计标准化误差直方图（对数纵轴）与标准正态密度。
- `load_error_region_statistics.csv`：区域负荷误差统计。
- `aggregate_statistics.json`：汇总数值。
