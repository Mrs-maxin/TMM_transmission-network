# 阶段E：新能源厚尾预测误差向节点电压与支路潮流的传播及越限概率

计算入口：`python cloud/tests/run_stage_e_tail.py`；计算程序`cloud/tmm_cloud/tail_stats.py`；输入为阶段D `20261021T202200/stage_d_montecarlo`两个运行点的检验场景（厚尾100000个，轻尾20000个，全部收敛，无剔除场景）。

## 比较设置

- 厚尾检验场景：OP1为t copula（ν=14.9），OP2为风电、光伏分组t copula（ν≈5.9）；轻尾检验场景为高斯copula。两组的边缘分布（kNN历史误差核密度，限于[0, 装机]）完全相同，因此两组差异只来自新能源误差的尾部相依，单站误差自身的厚尾在两组中都存在。
- 统计对象：非平衡节点电压幅值Vm与相角Va（各117个），186条支路首末端有功、无功，共978个；标准差低于数值阈值的对象（PV节点电压等）记为固定对象（OP1为42个，OP2为36个），不参与尾部统计。
- 尾部指数=(q99.5−q0.5)/IQR，正态分布约为3.82。厚尾组的抽样标准差由5个互不重叠的20000场景子集估计，差异显著性z=(厚尾−轻尾)/(子集标准差·√1.2)。
- 越限：电压超出[Vmin, Vmax]±10⁻⁶ p.u.；支路max(|S首端|, |S末端|)>rateA；Pmax>0的机组有功超出[Pmin, Pmax]。概率区间为Clopper-Pearson 95%。另按越限深度分级统计（电压0、0.0025、0.005、0.01、0.02 p.u.；支路负载率超出0、5%、10%、20%、30%）。
- 线性灵敏度：在预报运行点、厚尾检验场景最常见的机组无功运行方式下，由分布式平衡潮流雅可比矩阵求逆得到各对象对10个场站有功注入的灵敏度，乘以场站出力协方差得到新能源方差占比的线性估计。

- OP2（午间光伏与风电，分组t copula ν≈5.9）：尾部相依传播到大部分支路潮流和节点相角，40%左右的支路有功尾部指数显著高于轻尾组（z>3），支路有功尾部指数中位数由5.47增至5.91。差异最大的是机组12近区支路12–14（有功尾部指数4.97→5.48，z=16.6，下尾在10⁻⁴概率处外移约1个IQR，见`tail_exceedance_Pf_OP2.png`）以及区域3的108–109、109–110、105–108支路无功（z=13–17）。系统不平衡量超额峰度为2.51（轻尾组1.45），q0.5为−276 MW（轻尾组−251 MW）。
- OP1（夜间大风，t copula ν=14.9，接近高斯）：传播弱，支路有功尾部指数中位数3.69对3.64，18条支路z>3，集中在区域3风电送出断面94–96、94–95、100–101、103–110（z=7.5–9.0），q99.5和q0.5的移动均小于0.1个轻尾组标准差。系统不平衡量超额峰度为−0.08（轻尾组−0.14）。
- 两个运行点轻尾组的支路潮流本身已带厚尾（OP2支路有功超额峰度中位数1.28），来源是各场站边缘分布的厚尾和[0, 装机]截断，这部分不能由copula比较区分。
- 新能源方差占比与尾部指数差异的Spearman相关：OP1支路有功0.22、电压幅值0.49；OP2支路有功0.43、电压幅值0.14。对新能源注入灵敏的对象尾部差异较大，但单凭线性灵敏度只能部分解释差异，OP2中机组无功限值的频繁转换（14144种不同的机组运行方式组合，最常见组合仅占0.7%）也改变了电压幅值的分布。
- PV节点12、65、87等电压幅值的超额峰度达150–1400，标准差小于2×10⁻⁵ p.u.，来自对应机组少数场景达到无功限值后的电压偏移，不属于新能源误差尾部的传播。

两个运行点均无低电压场景（厚尾组概率上界3.7×10⁻⁵）。

- **10⁻³–10⁻²量级的越限事件在OP2出现，且对尾部相依敏感**：支路负载率超出5%的概率为1.53×10⁻³，是轻尾组的4.4倍，两组区间不重叠；6台机组（母线12、25、65、66、87、111，Pmin=0）同时出力低于0的概率为2.28×10⁻³，是轻尾组的3.3倍，区间不重叠。这228个场景与系统不平衡量低于−325.75 MW的场景完全一致：OPF给这6台机组只留了5% Pmax的下调裕度，而不平衡量按Pmax比例分担，所以它们在同一不平衡量下同时触及下限。这些场景对应风电、光伏同时大幅超出预测。节点83过电压概率为8.3×10⁻³，但两组差异不显著。
- OP1在10⁻³–10⁻²量级没有越限对象；支路负载率超出30%的概率两组区间重叠。OP1厚尾模型的ν=14.9接近高斯，两组越限概率无显著差异。
- **过电压概率接近1是运行点设置造成的**：OPF将多台机组电压设定在Vmax=1.06 p.u.，场景中这些机组达到无功下限后电压略高于1.06；超出0.0025 p.u.的概率在OP1为0，在OP2为4×10⁻⁵。母线66、25、37、17、9、100的过电压概率在0.33–0.66之间，越限深度均小于0.0025 p.u.。该现象不反映新能源误差的尾部。
- OP1中支路94–100、82–96的过载概率约0.14，OP2中支路100–103约0.43，原因是OPF运行点已使这些支路接近或达到rateA；OP1机组26超出Pmax的概率3.4%，来自夜间风电不足时的正不平衡量（q99.5为418 MW）。

## 判断

- 新能源误差的尾部相依部分传播到支路潮流和节点相角：在风电与光伏同时出力、分组t copula ν≈5.9的OP2中显著，在接近高斯相依的OP1中较弱，集中在区域3风电送出断面（已由数值实验支持，限于IEEE118、两个运行点、本阶段的误差模型）。
- 10⁻³–10⁻²量级的越限概率在OP2中出现于支路100–103负载率超出5%和机组低于Pmin两类事件，高斯copula会将其低估为约1/4–1/3（已由数值实验支持；轻尾组仅20000个场景，其概率区间较宽）。
- 节点电压的厚尾传播弱于支路潮流，原因是多数电压由机组调压维持，电压幅值的尾部主要受机组无功限值转换影响（已由数值实验支持；转换与尾部的定量关系尚未验证）。
- 过电压概率接近1来自OPF电压设定在上限，不作为新能源误差尾部的证据；若后续需要电压越限概率，应先将机组电压设定下调或放宽越限判定，这一处理尚未验证。

## 文件

- `tail_statistics_<OP>.csv`：978个对象的均值、标准差、超额峰度、分位数、尾部指数（厚尾/轻尾）、子集标准差、z值、线性灵敏度范数与新能源方差占比。
- `largest_tail_difference_<OP>.csv`：各类量尾部差异最大的10个对象。
- `violation_<事件>_<OP>_<heavy|light>.csv`：各对象及系统级越限次数、概率和95%区间（只列出次数>0的对象）。
- `graded_violation_probabilities_<OP>.csv`：分级越限深度的系统级概率与处于10⁻⁴–10⁻³、10⁻³–10⁻²的对象数。
- `stage_e_summary.json`：上述统计汇总、系统不平衡量统计、机组无功限值频率。
- 诊断图：`tail_difference_vs_renewable_share_<OP>.png`（新能源方差占比与尾部差异），`tail_exceedance_{Vm,Pf}_<OP>.png`（尾部差异最大对象的超越概率曲线）。
