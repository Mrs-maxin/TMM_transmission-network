# 阶段H：OP2潮流状态的GMM、标准TMM与分块TMM

计算入口：`python cloud/tests/run_stage_h_fit.py --result-stamp 20261022T125454 --workers 4`；计算程序`cloud/tmm_cloud/mixture.py`（derivation.md式(11)–(22)）、`cloud/tmm_cloud/state_model.py`（状态向量、式(15)雅可比矩阵）。输入为阶段一OP2的建模场景5256个和定阶场景1752个（float64存储，全部收敛，阶段G已核对与原始场景一致）。不使用检验场景。

## 状态向量与标准化

- 状态向量x = [117个非平衡节点电压实部e，虚部f，系统不平衡量λ（p.u.）]，维数235。机组出力Pg = Pg0 + α·λ，机组越限事件是x的函数。
- 式(11)：建模场景协方差特征分解，保留累计方差损失不超过10⁻¹⁰的方向，**d = 157**（舍去方差占比9.1×10⁻¹¹）。舍去的78个方向主要对应调压机组节点电压幅值固定所形成的弯曲约束。保留的最小特征值5.67×10⁻¹²，舍去的最大特征值5.18×10⁻¹²，两者之间没有明显间隔，d由10⁻¹⁰的方差损失阈值决定。数值可分辨下限p·eps·λ₁ = 3.3×10⁻¹⁴，不起作用。

## 共同波动强度方向（式(15)、(16)）

- 运行点：建模场景中出现最多的机组无功运行方式（10台机组处于无功限值，该组合只占建模场景的0.8%），在建模场景平均负荷倍率和平均新能源出力下求解，系统不平衡量11.4 MW，牛顿迭代5次，雅可比矩阵条件数6.7×10³。
- L_W选取10个新能源接入节点的有功方程行，接入节点由阶段B的`renewable_mapping.csv`读取并与运行点核对：风电106、94、96、17，光伏23、11、75、82、83、88。
- 映射到标准化坐标后的奇异值为82.9–6.5，**r = 10**（风电4、光伏6）。
- 主要分块模型为一个共同强度作用于全部10个新能源方向。OP2输入模型实际为风电、光伏两个独立强度，这是近似。另按任务说明计算了两强度变体：风电方向和光伏方向各有一个分量内的逆伽马强度，光伏方向对风电方向正交化，光伏块对风电块作t回归，其余方向对两块作高斯回归。

## 参数估计设置

协方差特征值下限10⁻⁷；ν∈[4.1, 10⁵]；平均对数似然变化的绝对值小于10⁻⁶时停止，最多3000次迭代；单次更新使平均对数似然下降超过10⁻⁸即判为不接受。初值为按第1、2、3主方向投影把建模场景等分为K组；先估计GMM，再以每个被接受的GMM为初值，取ν₀ = 12和200估计标准TMM、分块TMM和两强度变体；接受条件为收敛、对数似然不下降、各分量N_k > d + 2；每个K取建模场景平均对数似然最高的被接受结果，K*按式(22)取定阶场景平均对数似然最大者。候选K = 1、2、3、4、6、8，均满足N/K > d + 2。

全部126个估计（GMM 18个，其余三种各36个）均收敛且被接受，没有失败或分量退化。总计算时间465 s（4个并行计算，单线程BLAS），各方法累计计算时间：GMM 86 s，标准TMM 374 s，分块TMM 101 s，两强度变体534 s。

- 标准TMM的定阶对数似然在全部K上高于GMM和分块TMM，K = 8时比分块TMM高10.4，比GMM（K = 4）高11.0（已由数值实验支持）。
- **标准TMM的K*取在候选上界8**，K = 6到8时定阶对数似然仍增加0.47。候选K按任务说明固定，没有扩大，更大K是否更好尚未验证。
- 分块TMM与GMM几乎相同：同一K下对数似然只高0.4–0.6，各分量权重和有效场景数与GMM一致。强度只作用于10个新能源方向时，ν在5.3–10.9之间，但其余147个方向为条件高斯，不能表示这些方向上的厚尾。标准TMM的强度作用于全部157个方向，ν为10–36。由此推断，潮流状态的厚尾不只出现在新能源注入的线性灵敏度方向上，还来自机组无功限值转换和潮流的非线性（仅为当前假设，阶段I按方向分解检验）。
- 两强度变体比分块TMM只高0.1–0.2，光伏强度ν在大多数分量取下界4.1，说明光伏方向在该模型中需要比ν = 4.1更厚的尾部，原因尚未验证。
- 各方法的分量几乎为硬划分（N_k接近整数且四种方法一致），分量对应建模场景中明显分开的几组状态，与机组无功运行方式或系统不平衡量的关系尚未检查。
