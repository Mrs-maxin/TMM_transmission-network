# 阶段I：OP2边缘分布精度（与重尾检验场景的交流蒙特卡洛结果比较）

计算入口：`python cloud/tests/run_stage_i_marginals.py --result-stamp 20261022T125454`（指标计算），随后`--plots-only`（重画图形，复用同一设置的`marginal_metrics_OP2.csv`，原因见“计算过程记录”）。计算程序`cloud/tmm_cloud/propagation.py`（式(26)分层加扰Sobol点、加权分位数、KS距离、式(29)指标）和`cloud/tmm_cloud/state_model.py`（式(23)、(24)由状态点计算电压和支路功率）。

- 参照：阶段一OP2重尾检验场景100000个（`check_heavy`，float32存储，阶段G已核对与原始场景一致，块文件SHA256记录在`stage_g_identity.json`）。
- 被评价的分布：阶段H所选的GMM（K = 4）、标准TMM（K = 8）、分块TMM（K = 4）、两强度变体（K = 4），每个模型2^20 = 1048576个点，按π_k用最大余数法分配到各分量，每个分量使用独立加扰Sobol序列（随机抽样设置：熵2026102201 + 方法序号，按分量`SeedSequence(熵).spawn(K)[k]`）。
- 下限参照：5256个建模场景的经验分布（与模型使用相同的潮流计算次数，所有模型都由这些场景估计）。
- 全部设置在查看检验场景结果之前确定。唯一的事后改动是电压幅值的分组汇总方式（见下），模型和点集没有改变。

## 对象与指标

- 非平衡节点电压幅值Vm、相角Va（各117个），186条支路首末端有功、无功（Pf、Qf、Pt、Qt），支路负载率max(|S_from|, |S_to|)/rateA，系统不平衡量λ（MW），19台Pmax > 0机组的有功Pg。
- 指标：均值误差、标准差相对误差、0.1%/1%/99%/99.9%分位数误差（物理单位及以参照标准差σ为单位）、KS距离（模型加权分布函数与检验场景经验分布函数之差在检验场景点上的上确界，两侧极限都计入）。
- 检验场景标准差低于容差的对象列为固定对象，不计算指标（`fixed_objects_OP2.csv`）：**36个Vm**，均为始终保持电压设定值的机组节点（标准差4.5×10⁻⁸–6.4×10⁻⁸ p.u.，为float32存储舍入）。容差：Vm 10⁻⁶ p.u.、Va 10⁻⁵°、P/Q 10⁻³ MW/Mvar、负载率10⁻⁶、λ和Pg 10⁻⁶ MW。其余量没有固定对象。
- **Vm分组汇总（事后汇总方式改动）**：试算（每模型8192点，只用于检查程序）显示，机组节点Vm在建模场景经验分布下的KS也达到0.78。原因是机组调压时该节点Vm等于设定值，是一个点质量，检验场景float32存储使其位置有舍入偏移，连续分布模型也不能表示点质量。因此把17个非固定的机组节点Vm（部分场景达到无功限值）与64个PQ节点Vm分开汇总，额外绘图对象也不取机组节点Vm。两组的逐对象指标都保留在`marginal_metrics_OP2.csv`。

## 判断与证据状态

1. **标准TMM在除机组节点Vm以外的各量上KS最小**：支路功率和负载率KS中位数0.015，GMM 0.022–0.027，分块TMM和两强度变体0.023–0.028；Va为0.015对0.025–0.027；PQ节点Vm为0.048对0.088–0.092。（已由数值实验支持，限OP2、本阶段所选K*、2^20点。）
2. **所有模型都没有达到建模场景经验分布的精度**：支路量KS中位数，建模场景经验分布为0.011，标准TMM约为它的1.4倍，GMM和分块TMM约为2倍；99.9%分位数误差中位数，模型为0.4–0.7σ，经验分布为0.07–0.13σ。在相同的5256次潮流计算下，按经验分布直接计数的边缘分布精度高于本阶段的任一状态模型。（已由数值实验支持。）
3. **分块TMM与两强度变体相对GMM没有改进**，与阶段H的定阶对数似然一致；在支路量和Va上KS略大于GMM。（已由数值实验支持。）
4. **标准TMM以标准差精度换取分布形状**：支路量标准差相对误差中位数0.027，GMM为0.009；其KS更小来自K = 8的更细分量和厚尾分量的组合。（已由数值实验支持；更细分量是否是主要原因，尚未验证。）
5. **系统不平衡量λ的下尾在所有模型中偏轻**：0.1%分位数误差+60 MW（标准TMM）到+83 MW（GMM），经验分布+18 MW（5256个场景在0.1%分位只有约5个点，其值本身有较大抽样误差）。机组低于Pmin事件（λ < −325.75 MW）由λ下尾决定，阶段J中模型对该事件概率应偏低（仅为当前假设，阶段J检验）。
6. **支路100–103负载率上尾在所有模型中偏重**：99.9%分位数高0.016–0.018；检验场景负载率在0.87–0.97之间有一段较厚的下尾，模型均未表示（见`exceedance_branch_100-103_loading.png`）。支路77–82的上尾则偏轻，99.9%分位数低0.12–0.14。两条支路的超限概率在阶段J中应分别偏高和偏低（仅为当前假设，阶段J检验）。
7. **PQ节点电压幅值是模型误差最大的量**：与调压机组相邻的PQ节点（bus7、14、5、35、114、115）检验场景标准差只有1×10⁻⁵–4×10⁻⁵ p.u.，模型给出的分布宽得多，KS 0.20–0.47，99.9%分位数误差标准TMM 0.7×10⁻³–1.6×10⁻³ p.u.，GMM 1.7×10⁻³–4.0×10⁻³ p.u.。可能的原因是状态在直角坐标e、f中表示：分量内沿电压圆切向的线性波动会使|V|按约|V|·σ_θ²/2增大，bus7的Va标准差为1.3°（0.023 rad），对应约2.7×10⁻⁴ p.u.，与模型分布宽度同一量级；K = 8的标准TMM分量更小，误差也更小（仅为当前假设，未做分量内角度分解验证）。这一误差会使阶段J的电压越限事件(e)、(g)偏高。
8. 机组节点Vm的结果不作为模型精度依据：建模场景经验分布的KS也达到0.30（中位数），主要来自点质量和float32舍入（已由数值实验支持）。

## 计算过程记录

- 指标计算：每个模型约190–240 s（`metrics_console_output.txt`）。
- 第一次运行在指标文件写出后进入绘图，由于每条超越概率曲线绘制全部2^20个点且图例自动定位，单张图超过10 min，因此中止。改为每个方法只生成一次点集，并把曲线绘制在最接近1200个对数间隔尾部概率（10⁻⁷–0.5，两侧）的排序点上，图例固定位置；指标仍使用全部点。随后以`--plots-only`重画全部图形并写出汇总和运行记录。点集、熵和模型均与指标计算相同。
- 试算（8192点/模型）只用于检查程序，其数值不作为结果。
