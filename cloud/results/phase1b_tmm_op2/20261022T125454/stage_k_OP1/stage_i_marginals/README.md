## 判断与证据状态

1. **结论与OP2相同，但模型间差距较小**（已由数值实验支持）。
   - 标准TMM在支路量和Va上KS最小：支路量KS中位数0.020–0.021，GMM和分块TMM为0.023–0.028。
   - 所有模型都高于建模场景经验分布的0.016。
   - λ上三种模型的KS相近，为0.027–0.028。
2. **λ的两侧极端尾部在所有模型中都偏宽**：0.1%分位数低31–41 MW，99.9%分位数高24–27 MW；经验分布的误差小于1 MW。
   - 尾部偏宽已由数值实验支持。
   - 一种可能的原因：OP1风电出力在[0, 装机]内，λ分布的尾部有界，而模型分布的尾部无界（仅为当前假设）。
3. **支路94–100的尾部形状不对**：模型的99%分位数偏低，99.9%分位数偏高0.04–0.05。检验场景中该支路负载率的超越概率在1.25–1.33之间迅速下降到0（最大值约1.33），模型则平滑延伸到1.4以上（见`exceedance_branch_94-100_loading.png`）。这与OP2支路100–103的情况一致（已由数值实验支持）。
4. **PQ节点电压幅值误差与OP2相同**：KS最大的仍是与调压机组相邻的bus7、5、14，KS为0.45–0.52（已由数值实验支持）。原因与OP2相同，仅为当前假设。
