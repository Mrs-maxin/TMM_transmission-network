# 阶段K：OP1潮流状态的GMM、标准TMM与分块TMM

计算入口：`python cloud/tests/run_stage_h_fit.py --result-stamp 20261022T125454 --workers 4 --op OP1`。设置与OP2的阶段H相同（见`../../stage_h_fit/README.md`）。建模场景5256个，定阶场景1752个，全部收敛。

## 与OP2的差别

- OP1为凌晨4时运行点，6个光伏接入节点（23、11、75、82、83、88）在建模场景中出力恒为0。
- L_W只取出力有变化的4个风电接入节点（106、94、96、17）的有功方程行，取舍规则为建模场景出力标准差 > 10⁻⁹ MW。因此**r = 4**，奇异值15.7、13.7、5.8、3.0。
- 没有光伏强度，不做两强度变体。
- 输入模型为单一t copula（ν = 14.9）。
- 雅可比矩阵运行点：建模场景最常见的机组无功运行方式，5台机组处于限值，占2.0%；不平衡量54.1 MW，牛顿迭代4次，条件数6.7×10³。
- 式(11)：**d = 139**，舍去方差占比9.9×10⁻¹¹。保留的最小特征值1.39×10⁻¹¹，舍去的最大特征值1.29×10⁻¹¹，两者之间同样没有明显间隔。

## 判断

- 与OP2相同，标准TMM定阶对数似然最高，K*在候选上界。分块TMM与GMM只差0.1左右（已由数值实验支持）。
- OP1标准TMM的ν为23–48，比OP2的10–36大，即状态的厚尾程度较轻。这与OP1输入为单一t copula（ν = 14.9）、只有风电波动一致（已由数值实验支持；两者的定量关系尚未验证）。
- 分块TMM有一个分量ν = 294，接近高斯。
