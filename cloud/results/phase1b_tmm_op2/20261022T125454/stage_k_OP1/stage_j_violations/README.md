## 判断与证据状态

1. **10⁻⁴量级事件（任一支路 > 1.30·rateA）**：
   - 三种模型给出1.5×10⁻³–1.9×10⁻³，是检验值3.0×10⁻⁴的5–6倍，都在区间外（已由数值实验支持）。
   - 5256个建模场景中没有越限场景，计数只能给出上界7.0×10⁻⁴。
   - 原因与阶段I判断3一致：支路94–100负载率在检验场景中约1.33处截止，模型尾部无界。
2. **支路负载率 > 1.10和 > 1.20（10⁻²量级）**（已由数值实验支持）：
   - 模型均偏低，标准TMM为8.4×10⁻²和1.44×10⁻²，检验值为9.45×10⁻²和1.90×10⁻²；GMM和分块TMM偏低更多。
   - 建模场景计数与检验值一致，9.47×10⁻²和1.73×10⁻²，都在区间内。
3. **机组高于Pmax(c)（3.4×10⁻²）**：模型偏低19%–34%，建模场景计数3.22×10⁻²与检验值一致（已由数值实验支持）。
4. **全网电压越限(g)**：模型给出1.0×10⁻²–1.6×10⁻²，检验场景为0，与OP2相同，来自PQ节点电压幅值分布过宽（已由数值实验支持；机理仅为当前假设）。
5. **概率为0或接近0的事件**：模型与检验场景都在10⁻⁵以下，判为区间内，但这只说明两者都很小。
6. 总体上，OP1的结果支持OP2的结论：在相同的5256次潮流计算下，计数在10⁻²量级事件上比状态模型更准确；在10⁻⁴量级事件上，计数没有足够场景，状态模型则有5–6倍偏差（已由数值实验支持，限OP1）。OP1没有做重复性研究。
