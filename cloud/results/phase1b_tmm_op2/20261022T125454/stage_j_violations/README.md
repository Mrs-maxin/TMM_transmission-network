# 阶段J（1–2）：OP2运行限值越限概率

计算入口：`python cloud/tests/run_stage_j_violations.py --result-stamp 20261022T125454 --part table`；计算程序`cloud/tmm_cloud/violation_events.py`。模型点与阶段I完全相同（每模型2^20个分层加扰Sobol点，熵2026102201 + 方法序号）。事件定义和阈值在查看检验场景结果之前确定。

## 事件与阈值（由网络和运行点数据计算）

- 负载率 = max(|S_from|, |S_to|)/rateA，与阶段一阶段E相同。支路100–103的rateA = 151 MVA，支路77–82的rateA = 141 MVA（pglib_opf_case118_ieee）。
- (a) 支路100–103负载率 > 1.05；另给出阈值1.00–1.30（步长0.01）的超越概率曲线。
- (b) 任一机组低于Pmin。参与不平衡分配的机组（α > 0）有Pg = Pg0 + α·λ，机组i低于Pmin当且仅当λ < (Pmin,i − Pg0,i)/α_i，因此“任一机组低于Pmin”当且仅当λ低于这些比值中的**最大值**，即λ < −325.75 MW（多台机组同时取到该值，Pmin均为0）。任务说明写作“最小值”，按定义应为最大值，本阶段按最大值计算。α = 0的机组（Pmax = 0的调相机组）有功不变，不会越限。
- (c) 任一机组高于Pmax，等价于λ > min_i (Pmax,i − Pg0,i)/α_i = 325.75 MW。
- (d) 支路77–82负载率 > 1.00。
- (e) 节点83电压幅值 > Vmax + 10⁻⁶ p.u.（Vmax = 1.06）。
- (f) 任一支路负载率 > 1.05，以及 > 1.10。
- (g) 任一非平衡节点电压幅值 > Vmax + 0.0025 p.u.（平衡节点电压固定于设定值1.06，不会越限）。
- **等价性核对（检验场景100000个）**：直接由存储的机组出力判断，低于Pmin 228个、高于Pmax 1个；由λ阈值判断同为228个和1个，逐场景不一致数为0。存储的Pg与Pg0 + α·λ的最大偏差3.1×10⁻⁵ MW（float32舍入）。（已由数值实验支持。）

## 判断与证据状态

1. **四种状态模型对8个事件中的至少6个给出检验区间以外的概率，偏差为数倍到数百倍**。已由数值实验支持，限OP2和阶段H所选模型。
   - 支路过载(a)、(f)：模型偏高约5倍，约6.2×10⁻³–6.7×10⁻³，检验值1.22×10⁻³和1.53×10⁻³。
   - 机组低于Pmin(b)：模型偏低4–14倍。
   - 支路77–82过载(d)：模型偏低15–180倍。
   - 节点83电压(e)：模型偏高1.7–3.3倍。
   - 全网电压越限(g)：模型偏高180–620倍。
   - 落在区间内的只有检验场景仅有1个和5个越限的(c)、(f, 1.10)：标准TMM两者都在区间内，分块TMM只有(c)，GMM和两强度变体都不在。
2. **在相同的5256次潮流计算下，直接计数比任一状态模型更接近检验值**。已由数值实验支持。
   - 8个事件中，检验值全部落在建模场景计数自身的95%区间内。
   - (a)：计数0.95×10⁻³，检验值1.22×10⁻³。
   - (b)：计数1.71×10⁻³，检验值2.28×10⁻³。
   - (e)：计数8.75×10⁻³，检验值8.31×10⁻³。
   - 计数的代价是区间宽：5个越限场景时区间为估计值的−67%到+133%；0计数只能给出上界7.0×10⁻⁴。
3. **偏差方向与阶段I的尾部分位数误差一致**：支路100–103负载率上尾偏重，支路77–82上尾偏轻，λ下尾偏轻，PQ节点电压幅值分布过宽。越限概率的偏差来自这些边缘分布尾部误差，不是事件计算的问题。已由数值实验支持：独立的2^17点重算给出相同的(a)概率6.1×10⁻³。
4. **标准TMM在(b)、(d)、(e)、(g)上比GMM和分块TMM更接近检验值，但仍在区间外**：
   - (b)：5.9×10⁻⁴，GMM 1.7×10⁻⁴，检验值2.28×10⁻³；
   - (g)：7.1×10⁻³，GMM 2.4×10⁻²。
   - 在(a)、(f, 1.05)上各方法相同。

   已由数值实验支持。
5. **全网电压越限(g)的模型概率主要是电压幅值弯曲误差的结果**。仅为当前假设，按分量和节点分解尚未做。
   - 检验场景只有4个越限场景；模型对与调压机组相邻的PQ节点给出过宽的电压幅值分布（阶段I判断7）。
   - 节点电压直接由e、f重构，Vm = |e + jf|。
   - 直角坐标下的分量内线性波动不能保持调压节点附近的电压幅值。
6. **支路过载概率偏高的原因尚未确定**，以下两点均仅为当前假设。
   - 已排除一种解释（已由数值实验支持）：模型中支路两端调压节点100、103的电压幅值有约3.4×10⁻⁴ p.u.的离散，但两端同向变化，支路无功标准差0.55 Mvar与建模场景一致，有功标准差也一致。
   - 检验场景的超越概率曲线在1.08处截止，模型曲线延伸到1.11–1.17。
   - 一种可能的解释：新能源出力在[0, 容量]内截断，使支路潮流有物理上界，而高斯和t分量的尾部没有上界。
7. **重尾输入对越限概率的影响**：轻尾检验场景的(a)为2.5×10⁻⁴，是重尾检验值的约1/5；(b)为7.0×10⁻⁴，约为1/3。已由数值实验支持。
