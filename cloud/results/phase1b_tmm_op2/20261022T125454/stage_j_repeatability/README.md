## 设置

- 每次重复r = 1…10：
  - 随机抽样设置：熵2026102200 + r，`SeedSequence.spawn(4)`，与阶段D相同，取前两个子序列。
  - 从OP2重尾输入模型（阶段一阶段C的分组t copula）新抽取建模场景5256个、定阶场景1752个。
  - 用阶段一的牛顿-拉夫逊潮流计算（`montecarlo.run_set`，float64存储）求解。场景块位于`rep<r>/`，不进入Git。
  - 按阶段H的全部设置重新标准化、确定共同强度方向并估计四种模型，各方法按式(22)自行选K。

- 计数给出两种：只用5256个建模场景；用建模和定阶共7008个场景。后者与模型使用的潮流计算次数相同。
- 参照值：阶段一OP2重尾检验场景100000个的计数。
- 计算量：每次重复约500–600 s，其中估计约360–470 s，潮流计算约30 s，四个模型的点估计约120 s；合计5377 s，低于3 h，因此按R = 10完成。

## 判断与证据状态

1. **结论：在本运行点和本阶段的模型设置下，TMM没有比计数更准确地估计10⁻³量级越限概率**（已由数值实验支持，限OP2，R = 10）。
   - 标准TMM的重复间离散最小，但每次都有同方向的大偏差。(a)的10%–90%范围为4.74×10⁻³–6.58×10⁻³，相对中位数的宽度约35%；7008个场景计数的相应宽度约78%。
   - 标准TMM 10次全部偏向同一侧且都在检验区间外，10次的最小到最大值：(a) 4.3×10⁻³–8.4×10⁻³，中位数偏高约+330%；(b) 2.8×10⁻⁴–7.7×10⁻⁴，偏低约−76%；(d) 2.4×10⁻⁵–2.4×10⁻⁴，偏低约−96%。
   - 7008个场景计数的相对误差绝对值中位数为19%–25%，均方根相对误差为30%–35%（事件(a)、(b)、(d)、(f, 1.05)）。
   - 四种模型的均方根相对误差：(a)、(f, 1.05)为260%–370%，(b)为74%–77%，(d)为92%–95%。计数低2–12倍。
2. **计数误差与二项分布抽样误差一致**：
   - p = 1.22×10⁻³、n = 7008时，理论相对标准差为1/√(np) = 0.34，观测的均方根相对误差为0.32。已由数值实验支持。
   - 但10次重复的计数中位数都低于检验值，(b)、(d)低19%–35%。把10次的7008个场景合并（共70080个）：
     - (a) 1.04×10⁻³ [0.82, 1.31]×10⁻³；
     - (b) 1.73×10⁻³ [1.43, 2.06]×10⁻³；
     - (d) 6.6×10⁻⁴ [4.8, 8.8]×10⁻⁴；
     - (f, 1.05) 1.18×10⁻³ [0.94, 1.47]×10⁻³。

     其中(b)的区间与检验值区间[1.99, 2.60]×10⁻³不重叠。
   - 原因核对（`input_tail_check/`）：系统不平衡量与新能源总出力误差的相关系数为−0.998。在检验场景的99.77%分位（330.9 MW）处：
     - 检验场景的超越概率为2.30×10⁻³；
     - 同一输入模型新抽取的10⁶个误差向量给出2.04×10⁻³ [1.95, 2.13]×10⁻³，差1.7个标准误差。
     - 其他分位处检验场景也偏高1.1–1.3个标准误差。

     由此判断，检验场景本身的尾部因抽样波动偏高约13%，合并计数则偏低，两者合起来造成区间不重叠，不是设置差别。这一判断只在输入层面得到支持（已由数值实验支持）；事件层面没有用更大的检验场景组核对（尚未验证）。
   - 检验值的抽样误差约为±7%（1个标准误差，228个越限场景），远小于模型的偏差，不改变判断1。
3. **模型偏差来自分布形状，不来自建模场景的随机性**：阶段J（1–2）中由原建模场景得到的标准TMM估计落在这里的10%–90%范围内，(a) 6.20×10⁻³、(b) 5.9×10⁻⁴。重新抽取建模场景不能消除偏差。偏差方向与阶段I的边缘分布尾部误差一致。已由数值实验支持。
4. **GMM、分块TMM和两强度变体的重复间离散大于标准TMM**：(b)的范围分别为7.7×10⁻⁵–1.5×10⁻³和约1.0×10⁻⁴–1.3×10⁻³，标准TMM为3.5×10⁻⁴–6.6×10⁻⁴。离散与K*在4和6之间变化有关。已由数值实验支持；离散与K*的对应关系尚未逐次检查。
5. **10⁻⁵量级事件(f, 1.10)**（检验值5.0×10⁻⁵，检验场景只有5个越限）：
   - 计数在8次或6次重复中为0；
   - 标准TMM中位数1.5×10⁻⁴，偏高约3倍；
   - 分块TMM的中位数4.2×10⁻⁵接近检验值，但范围为1.6×10⁻⁵–1.9×10⁻⁴。

   检验值本身的95%区间为1.6×10⁻⁵–1.2×10⁻⁴，这一事件上的比较只能作为参考，结果不稳定。
