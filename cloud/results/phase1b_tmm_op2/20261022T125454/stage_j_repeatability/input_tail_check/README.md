# 阶段J补充核对：重尾检验场景的新能源总误差尾部

计算入口：`python cloud/tests/run_stage_j_input_tail_check.py --result-stamp 20261022T125454`。不做潮流计算。

## 计算内容

- 比较量：每个场景10个新能源场站出力之和减去预测之和（MW），单站出力在[0, 装机]内，与阶段D相同。
- 比较对象：阶段一OP2重尾检验场景100000个，和同一输入模型新抽取的10⁶个误差向量。随机抽样设置：熵2026102400 + b，b = 0…9，每组100000个。
- 原因：系统不平衡量λ与这一总误差的相关系数为−0.998，事件(b)“任一机组低于Pmin”（λ < −325.75 MW）基本由总误差上尾决定。

## 判断

在各分位处，检验场景的新能源总误差上尾都比输入模型高约4%–16%，偏差为1.1–1.7个标准误差，属于100000个场景的抽样波动范围（已由数值实验支持）。检验场景作为参照，其10⁻³量级事件概率本身约有±10%–15%的抽样误差。由此推断，事件(b)的输入模型真值约为2.0×10⁻³。这一推断只依据输入层面的近似线性关系，没有用更大的潮流检验场景组核对（尚未验证）。
