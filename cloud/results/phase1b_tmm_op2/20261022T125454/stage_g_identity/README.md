## 与任务说明的差别

任务说明写的是“支路100–103负载率超过1.05·rateA的场景153个”。实际情况是：153是阶段一阶段E分级统计中任一支路超过1.05·rateA的场景数，支路100–103单独为122个。阶段一总结中“支路100–103负载率超出rateA 5%以上：1.53×10⁻³”的说法因此不准确，应为“任一支路负载率超出rateA 5%以上：1.53×10⁻³（支路100–103单独为1.22×10⁻³）”。阶段一目录按要求不作修改，更正记录在本目录和本任务的总结中。

上述差别来自事件定义，不来自场景数据：第1、2项表明重新生成的场景与原始场景相同。因此没有停止计算，阶段J中事件(a)按支路100–103单独统计，事件(f)按任一支路统计。
