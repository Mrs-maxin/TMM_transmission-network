# 分布精度与潮流验证

版本restart-v1。以下为预先登记的初始数值目标，不是电网安全标准、已达精度或投稿要求。配置在最终MC生成前冻结；任何修改只使用训练/验证/校准，并登记版本。

## 先核查电压和线路功率是否算对

| 检查 | 初始目标或要求 |
| --- | --- |
| 非参考P、PQ的Q残差 | 最大1e-8 p.u. |
| PV电压平方残差 | 最大1e-8 p.u.² |
| 独立交流求解容差 | 1e-10 p.u. |
| 同输入电压幅值差 | 最大1e-6 p.u. |
| 对齐相角差 | 最大1e-5 rad |
| Qg及平衡Pg差 | 最大1e-5 p.u. |
| 支路双端P/Q/MVA差 | 最大1e-3 MW/MVAr/MVA，分别登记 |
| Q控制 | 最终模式、参考、触限方向与限值等号一致；无静默裁剪 |
| 导纳/导数 | 独立导纳、有限差分和二次恒等式核查，阈值按缩放与舍入误差登记 |

固定模式至少256组同输入诊断，包含零扰动和近边界输入；此数量是计划，不是已通过。校准集中所有未回退样本对独立AC核查漏触限，成本入账。无法评估的输入保留，不能删到达标。

## 再核查完整分布

主要参照是最终独立完整交流MC。全部节点、机组和线路两端给均值、标准差、1%/5%/50%/95%/99%分位数；代表对象给完整PDF/CDF。

| 量 | 初始均值绝对误差目标 | 初始分位数绝对误差目标 |
| --- | --- | --- |
| 电压幅值 | 1e-4 p.u. | 1e-3 p.u. |
| 对齐相角 | 1e-3 rad | 5e-3 rad |
| Pg、线路P | 1 MW | 5 MW |
| Qg、线路Q | 1 MVAr | 5 MVAr |
| 线路MVA | 1 MVA | 5 MVA |

连续非退化输出的标准差相对误差初始目标5%，CDF网格最大差初始目标0.02。近零方差采用原单位绝对误差，不报无意义百分比；工程容差、绝对值和分母同时保存。目标是否满足需结合MC区间与积分误差，不凭曲线视觉放行。

201个CDF分位网格只给网格最大差，不改称精确KS。需同时保存各网格间的MC质量和数值CDF误差；只有完成区间内极值/误差界核查才报告KS。模型抽样对MC的两样本KS可以另报，但明确包含模型抽样误差，不替代半解析核查。

PDF对照以MC归一化直方图为背景，记录分箱；TMM密度方法和网格步长单列。比较分箱质量与完整CDF，避免把MC平滑带宽或数值差分波动当作物理分布偏差。

## 固定PV电压与受限机组

固定PV幅值、已固定Qg和固定非参考Pg可能存在点质量。登记CDF左右极限、点质量和工程容差带，单独画固定值标记。连续TMM对PV幅值的泄漏照实报告；不得强行平滑MC原子、径向投影TMM或仅把PV电压分布设成固定值。

主CDF误差表区分连续、确定和混合输出，不能用连续CDF目标否定一个数值上接近设定值的点质量，也不能借此忽略模型支持条件不一致。

## MC不确定性与积分误差

源荷输入IID，均值和标准差给批次/重抽样区间并说明适用条件；分位数给次序统计区间，概率/CDF给二项区间或声明范围的同时带。多个对象的同时覆盖与逐对象95%区间分开。

Sobol随机化重复只描述积分误差，不是交流参照区间。同模型独立样本只核查积分，最终源荷MC检验概率模型。有限MC看不清的差异记不足，不改成0。
